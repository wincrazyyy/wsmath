Homepage content

Edit hero and proof-pills for the homepage.

Hero title (name / brand)

Big title at the top, e.g. “Winson Siu”.

hero.title

Hero subtitle

Short English line under the title.

hero.subtitle

Hero tagline (Chinese)

Chinese line explaining what you do.

hero.tagline

Hero image path

Path to the hero image in /public, e.g. /hero.png.

hero.imageSrc

JSON path: hero.imageSrc

File public path: /hero.png

Used on the homepage hero. Upload a square-ish PNG image with transparent background.

On save, this will write to public/hero.png.

Hero stat value

Big number shown in the hero.

hero.stat.value

Hero stat label (English)

Short label next to the number.

hero.stat.label

Hero stat sublabel (Chinese, optional)

Optional smaller Chinese label.

hero.stat.subLabel
